# Мини-система сбора и анализа данных
### Цель
Cоздать простую end-to-end систему, которая генерирует данные, сохраняет их и позволяет анализировать через Redash и Jupyter Notebook.
### Компоненты системы
1. Генератор данных (Python-скрипт);
2. База данных — MySQL;
3. Redash — дашборды и визуализации.
### Вариант
Погодная станция. Датчик отправляет показания: температура, влажность, давление, скорость ветра.
### Инструкция по запуску
- git clone https://github.com/Faravells/dvfu-data-analyst
- cd dvfu-data-analyst
- docker-compose up
